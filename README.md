# Podcast Clips

Outil pour les créateurs de podcasts : transforme leurs propres vidéos longues en clips verticaux sous-titrés et
les envoie sur leur compte TikTok (brouillon, ou publication après choix explicite des réglages par le créateur).

- Site : https://youlisissoko.github.io/tiktok-callback/
- [Conditions d'utilisation](TERMS.md)
- [Politique de confidentialité](PRIVACY.md)
- Page de retour de connexion TikTok : `callback/`
